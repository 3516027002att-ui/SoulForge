# 原生读取安全（替代手工台账）

目标已有精确身份时，使用该身份读取或调用 `find_references`，不先登记台账，也不强制重复名称搜索。需要参数、事件、脚本、位置及路径时使用关联上下文；普通字段读取保持轻量。

目标存在歧义时使用候选返回的身份定位，不选择第一项，不从名称或数字规律编造身份。工具的原生读取证明由宿主记录；写入使用实际目标、当前版本及已读取字段。

关联片段、搜索摘要和大纲不能替代完整事件或完整脚本读取。覆盖不足或存在未解析来源时，结论是尚未查全，不是没有引用。

写入工具返回已提交但验证失败时，不得重复写入；检查操作记录和恢复入口。不要调用旧台账工具，不填写 searchId 或修改次数。
