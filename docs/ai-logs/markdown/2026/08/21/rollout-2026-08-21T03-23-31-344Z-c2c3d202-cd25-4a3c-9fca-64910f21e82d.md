## 崩溃特征

- `ExpCode: 0xC0000005` = 访问违例（Access Violation），本质是**代码尝试读写了一个非法/无效的地址**，属于空指针 / 悬垂指针 / 越界数组类问题，而不是断言类错误。
- `ExpAddress: 0x00000001401C8796` 是一个**固定地址**（x64 程序基址 0x140000000 附近），说明崩溃每次都发生在同一条指令上，属于**可复现、触发条件确定**的 bug，不是随机内存损坏。

针对道具/商店，`gameparam` 里有几张表是最容易在这种场景下炸的：

1. **ShopLineup（商店陈列）引用了不存在的 ItemLot / Goods / 道具 ID**，或 cost 超出合理范围。游戏构建商店列表时对 ID 做间接寻址，解出一个无效指针 → 空指针解引用。
