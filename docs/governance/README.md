# Historical compatibility material

This directory is retained because scoped release/deferral consumers still read meaningful parts of it. Its old claim/seal/fingerprint/projection workflow is retired and does not grant authority or impose a whole-repository freshness prerequisite on product work.

Use GitHub Issues for work, CI/check reports for actual execution, `docs/DECISIONS.md` for owner choices, and the repository `AGENTS.md`/`ARCHITECTURE.md` for stable entry points. Product safety, native correctness and release checks remain independent boundaries. Existing artifacts and rescue material are not cleanup targets merely because the old workflow was retired.
