## 3. 三个跨节的系统性偏移源

这三条不属于任何单一章节，但会同时污染所有章节。

**行号锚点会过期。** 全文用 `file:line` 定位——这让它能精确指导，也让它脆。任何代码改动或文档插入都会让一批锚点失效，而**失效的锚点长得和有效的一模一样**。本轮实例：一份暂存件称 `TaeWorkbenchPanel.tsx:1036` 已漂到 `:1068`，实测 `:1036` 完全正确——是我把两个不同的调用站点（`readTaeChrbndPreview` 与 `sampleFlverPose`）搞混了。**先 grep 符号名确认位置，再用行号当加速器，不要当真相。**

**自指的计量在写下去那一刻就过期。** 文档里的字节数、行数、哈希都有这个毛病：写入行为本身改变被写入的量。本轮已把 msssion 表格里的字节/哈希两格改成「会变，见下」「勿用于校验」，并留了 `grep -c "24\.9\.0"` 作判别器。**判版本用 grep 数特征锚点，不要用字节数。**

**6988 行读不完，跨节矛盾因此隐形。** 同一概念在不同章节被定义得不一样（§24.16 那一串「第 N 种约定」就是这个现象的产物）。弱 agent 只读被指到的那一节，就只拿到一种约定，**并且不知道还有别的**。**动任何跨层概念之前，先 grep 该概念在全文的所有出现点，一起读。**
